# Mobile AI Application (CAT1 Group 14)

This repository contains the complete codebase and backend test suite for our Mobile AI Application project (`SWE3409` & `SWE3513`).

## Project Structure

The project is divided into two main modules:

1. **`swe3409-cat1-g14/` (Mobile Frontend)**
   - Built using **React Native** and **Expo**.
   - Features a custom component structure (`src/components/`, `src/screens/`).
   - Includes full navigation flow (Home Dashboard to Interactive Chat Interface) and API integration layers.

2. **`swe3513-cat1-g14/` (Backend & Logic)**
   - Contains Python test suites and backend assignment logic (`A1-A5`).
   - Powers the core processing rules and data validation behind the application.

## Getting Started (Frontend)

To run the mobile app locally:

```bash
# Navigate to the mobile app directory
cd swe3409-cat1-g14

# Install dependencies
npm install

# Start the Expo development server
npx expo start
